# Defects found by the Round 30 ledger pass (not fixed here)

Found while building the file ledger, the architecture map and the regression matrix at
`29e4356`. Each is reported for assignment, not fixed in this workstream. Severity and class
follow the Round 30 brief (P0–P3, Info; confirmed vulnerability / functional bug / design
weakness / integration footgun / operational blocker / data gap / accessibility / doc mismatch /
suspected).
