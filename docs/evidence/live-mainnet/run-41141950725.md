## Reading this

- The replay's transactions are other people's, replayed unsigned against today's state with the intent an honest agent would declare. A program with no evidence is refused by policy, and a transaction whose inputs moved since fails simulation; that is the design, not a defect. The honest-transfer pass is the one that measures approvals.
- A refusal is never counted here as a correct or an incorrect one: this run has no ground truth about intent. `BlockedButExecuted` (L8) and the *Watched rows* are where a candidate false refusal is shown.
- `BlockedButExecuted` in L8 is the alarm firing as designed: Graphite refused a transaction somebody else executed.
- `inclusion_assurance` is `single_provider` unless a witness RPC was configured.
- The Core simulates with `replaceRecentBlockhash: true` (graphite-core/src/rpc_client.rs, `simulate_config`), so a stale blockhash cannot by itself make L3 fail; the fresh pass measures that rather than assuming it.
