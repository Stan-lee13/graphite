# Round 40 — the open decisions, decided

On 2026-10-25 the owner delegated every open owner decision of Round 39 to the technical lead
("choose the best option for everything", "don't hide any issue"). This page records each decision,
the options, why this one, which Constitution principles it touches
(`graphite-engineering-skill/CONSTITUTION.md` v1.1), and where it is implemented and tested. A
decision here never weakens a gate; where it changes behaviour, the change is stricter, or it
removes a false refusal by correcting the evidence the refusal rested on.

What this page cannot decide: repository settings only an admin can change on GitHub (rulesets,
the `release` environment, private vulnerability reporting), the owner's signing key, an
independent audit and a production deployment. Those remain in
[`RESIDUAL_RISK_AND_OWNER_GATES.md`](RESIDUAL_RISK_AND_OWNER_GATES.md) §1, with the exact steps.
